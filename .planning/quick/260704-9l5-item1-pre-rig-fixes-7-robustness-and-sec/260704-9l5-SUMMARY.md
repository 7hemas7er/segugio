**Seven atomic pre-rig hardening fixes: real-frame GPU latency gates (p95 162ms), a self-healing NDI receiver + startup discovery doctor, SEGUGIO_OBS_* credential wiring, a rotating post-mortem log, an OBS-health badge, and a shared-secret + CSRF gate on the console's mutating routes.**

## Accomplishments

- **Fix #1 (latency):** the two `@pytest.mark.gpu` latency tests now decode REAL dog frames from `tests/fixtures/looptest/cam_wide_9898282.mp4` (downscaled to a production-representative 1080p), a dedicated-throwaway-tracker warmup proves non-zero detections, and a p99/max TAIL gate + an ABSOLUTE-headroom preview check replaced the flaky two-OFF-run noise band. **Measured on the rig (venv312, AC, RTX 4000 Ada), 1080p ×4-cam eager-FP16 + native ReID: p50=143.7ms, p95=162.0ms, p99=174.4ms, max=203.8ms** — comfortably under the 300ms RBT-05 budget.
- **Fix #2 (RBT-04):** the NDI receiver per-iteration body is fault-isolated (a transient cyndilib/cv2 exception is throttled-logged + coasted; the daemon thread survives), and the live `run()` loop supervises the source every ~30 ticks, restarting any dead receiver via the idempotent `start()`.
- **Fix #3:** `SEGUGIO_OBS_HOST/PORT/PASSWORD` are resolved by `_obs_credentials()` and threaded into `ObsWsController(host, port, password)`; a set OBS password now reaches the controller instead of silently connecting unauthenticated. Docs reconciled.
- **Fix #4:** `configure_logging(log_dir=...)` is called from both `python -m segugio` and `run_console()`, adding a rotating `segugio.log` post-mortem sink; the crash-isolation import gate stays green (lazy in-body import).
- **Fix #5:** `obs_connected` flows ObsWsController → DirectorStatus → status.json → GET /status → a console OBS-health badge, so a down OBS (throttled no-op cuts) is visible instead of silent.
- **Fix #6:** a startup NDI discovery doctor (`preflight` + the pure `_diagnose_sources`) emits a per-camera `ndi_source '<name>' (cam <id>) NOT FOUND` operator error for a drifted/absent source instead of silently coasting.
- **Fix #7 (SECURITY):** `/score`, `/run`, `/command` now require `Authorization: Bearer <SEGUGIO_CONSOLE_SECRET>` + a same-Origin (CSRF) check when the secret is set; the console page carries the secret for its own POSTs; `SEGUGIO_CONSOLE_HOST` overrides the bind; the orchestrator warns loudly when the console is secured but OBS has no password.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed a warmup that polluted the batched-detection model (test artifact I introduced)**
- **Found during:** Task 1 (GPU latency harness)
- **Issue:** The plan's non-zero-detection warmup called serial `.track()` on `next(iter(trackers.values()))`. That first tracker's `.model` is ALSO the model the batched loop reuses for its single detection forward — the serial `.track()` warmup registered Ultralytics' own `on_predict_start` on it, which broke the native-feats hook so `result.feats` was stripped and the native BoT-SORT encoder was handed the raw frame → `'numpy.ndarray' object has no attribute 'cpu'`, coasting every tick (defeating the "ReID cost is timed" must-have and inflating p95 to ~345ms).
- **Fix:** Warm up a DEDICATED throwaway `PerCameraTracker` (disjoint from the loop's `trackers`) so the loop's shared model stays pristine. Verified by direct `batched_detect_dispatch` reproduction (all 4 cams get confirmed tracks) and by the final gpu run logging `BoT-SORT native-feature ReID engaged`.
- **Files modified:** tests/test_latency.py
- **Committed in:** `bfc844e`

**2. [Rule 2 - Missing Critical] Downscale looptest frames to 1080p**
- **Found during:** Task 1
- **Issue:** The fixture is 4K (3840×2160); feeding it raw measured 4K preprocessing the production 1080p feeds never incur, pushing p95 to a non-representative ~345ms.
- **Fix:** Downscale each decoded frame to a production-representative 1080p (`_LOOPTEST_TARGET_HEIGHT`) before feeding the loop. p95 dropped to 162ms (representative).
- **Files modified:** tests/test_latency.py
- **Committed in:** `bfc844e`

**3. [Rule 2 - Missing Critical] Authenticate the score-entry component's own /score POST**
- **Found during:** Task 7
- **Issue:** The plan named console.html's `post()` helper, but `/score` is POSTed by `src/segugio/ui/static/score-entry.js` (used by both the console modal and the dedicated /score-entry page). Without the Bearer header there, a secured console could not publish scores.
- **Fix:** Added the `Authorization: Bearer window.__CONSOLE_SECRET` header to `score-entry.js` `submit()` and inlined `window.__CONSOLE_SECRET` into `score-entry.html` too (in addition to console.html).
- **Files modified:** src/segugio/ui/static/score-entry.js, src/segugio/ui/templates/score-entry.html
- **Committed in:** `9928d52`

**4. [Rule 2 - Robustness] Defensive parsing of SEGUGIO_OBS_PORT**
- **Found during:** Task 3
- **Issue:** A non-integer `SEGUGIO_OBS_PORT` would raise `ValueError` at startup (a crash path — violates "nessun crash ammesso").
- **Fix:** `_obs_credentials()` coasts to the default port with a warning on a non-integer value.
