score_stream (src/segugio/synth/score_stream.py):
  @dataclass(frozen=True) ScoreSample: { tick: int, cam_id: str, score: float }   # score normalized [0..1]
  def score_stream(rng: numpy.random.Generator,            # INJECTED — determinism (TST-02)
                   scenario: str,                          # "ping_pong" | "tie" | "dropout" | "recovery"
                   cam_ids: list[str],
                   n_ticks: int,
                   noise: float = 0.02) -> list[ScoreSample]
    Scenario shapes (the deterministic base, jitter added from rng only):
      ping_pong : two cameras alternate as leader over time (the FSM must NOT chase this)
      tie       : two cameras hold near-equal scores (tiebreaker / no-oscillation case)
      dropout   : the leader's score collapses for a short window then is absent (coast/TTL case)
      recovery  : a dropped camera's score returns after a gap (rejoin case)

feed_death (src/segugio/synth/feed_death.py):
  @dataclass(frozen=True) FeedEvent: { tick: int, cam_id: str, alive: bool }
  def feed_death(rng: numpy.random.Generator,
                 cam_ids: list[str],
                 n_ticks: int,
                 death_at: dict[str, int] | None = None,   # explicit death tick per camera
                 recover_after: int | None = None) -> list[FeedEvent]
    Produces a per-tick liveness timeline: a camera is alive until its death tick, then dead,
    then alive again at death+recover_after (if recover_after set). Watchdog (P3/P5) tests this.

Determinism contract (RESEARCH.md Pattern 4 + Pitfall 3):
  - rng is the ONLY randomness source; caller does `np.random.default_rng(seed)` and passes it.
  - NO module-level RNG, NO np.random.seed() (global), NO time.time()/datetime.now().
  - time == the synthetic tick index. same seed -> identical list; different seed -> different list.
