Build the operator console (D-02/D-04): a separate-process Flask app serving one Italian page with score entry (discipline selector + 3 per-discipline field sets), run start/stop, override controls, and a live director-status read-back. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/tablet (dedicated WiFi) → Flask app (0.0.0.0 bind) | The console is reachable from a tablet over the dedicated WiFi (D-02/D-04); the dedicated LAN is the trust boundary — no auth in v1 is an ACCEPTED, documented decision for a localhost/field tool, not an oversight. |
| operator form input → atomic score/command files → OBS overlay / orchestrator | Crafted POST values must not write arbitrary paths or inject overlay-control content into the OBS read-from-file source. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05-01 | Tampering | POST field → atomic file path (path traversal / arbitrary write) | mitigate | Channel write paths are FIXED server-side (channel_dir + constant filenames); the operator never supplies a path. Discipline is whitelisted to the Discipline enum; unknown discipline → 400. |
| T-05-05-02 | Tampering | Text injection into the OBS read-from-file overlay | mitigate | render_overlay_text formats into a constrained Italian line; field values are length-bounded/escaped so a crafted value cannot inject overlay control content. |
| T-05-05-03 | Tampering | Contradictory force+release command reaching the FSM | mitigate | OperatorCommand/OverrideCmd __post_init__ rejects both-set → 400 at the UI boundary; the loop never sees a malformed command. |
| T-05-05-04 | Spoofing/Elevation | 0.0.0.0 bind exposes control to anyone on the WiFi | accept | Documented: the dedicated WiFi LAN is the trust boundary; no auth in v1 is an accepted decision for a single-operator field tool (D-02). Not internet-facing. |
| T-05-05-05 | Information | UI crash propagating to the director | mitigate | Separate process, files-only IPC (D-03); segugio.ui imports nothing heavy → a UI exception can never touch the orchestrator (RBT-04). |
</threat_model>
