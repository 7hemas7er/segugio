## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config → HTML render | `event_name` / `logo_path` / theme colors land in the served HTML via Jinja (operator-authored config — trusted, but autoescaped). |
| live video ↔ overlay compositing | The transparent page composits over program video in CEF; a non-transparent background or white flash is a broadcast defect. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Tampering | config strings (event_name/logo_path/theme) injected into HTML | mitigate | Jinja autoescape ON (Flask default) for all `overlay_cfg` values; theme colors land in a CSS-var context; logo_path in an `<img src>` is autoescaped; Task 2 asserts no raw `innerHTML` assignment of config in the inline script |
| T-11-02-02 | Denial of Service | perpetual CSS animation on a full-frame transparent CEF source (GPU/encode spike on the shared OBS box) | mitigate | Animations are events-only (enter/exit/pulse), transform/opacity only; Task 1+2 forbid `animation: ... infinite`; the run timer is a textContent update, not an animation (the actual timer loop is 11-03) |
| T-11-02-03 | Information Disclosure | overlay covering the action area (not a security threat but a HARD product invariant) | mitigate | Title-safe band capped ~18%, bottom-left plate + bottom-right bug; Task 2 asserts no full-width/top-anchored banner (OVL-03) |
| T-11-02-SC | Tampering | npm/pip/cargo installs | mitigate | NO package installs (vanilla HTML/CSS, no build step); zero new Python dep; no Package Legitimacy Gate needed |
