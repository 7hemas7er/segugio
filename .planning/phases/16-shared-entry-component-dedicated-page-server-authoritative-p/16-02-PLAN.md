<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator free-text → DOM (CEF / browser) | Untrusted free-text values (freestyle `nome`, server-echoed error messages) cross into the rendered page and, downstream, the on-air overlay. |
| `GET /score-entry` → injected `score_cfg` blob | The server-rendered profile blob reaches the client; it must carry no float-drifted numerics and no heavy-import dependency. |
| `score-entry.js` → `POST /score` | The component sends RAW inputs; the server (Plan 01) is the authority. The client must never send a computed total. |
