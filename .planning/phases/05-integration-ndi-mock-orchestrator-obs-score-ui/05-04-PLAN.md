<objective>
Build the feed watchdog: pure liveness math that deduces whether each camera's feed is alive from the last-NEW-frame timestamp (never the NDI source/connection state — the 75-min freeze trap), with the `watchdog_timeout` (=0.8s) threshold and an anti-jitter grace, exercised on injected `(now, last_frame_ts)` pairs. Then prove the end-to-end fallback+rejoin: a dead feed flips `alive[cam]=False`, which `DecisionEngine.tick(...,alive=...)` already excludes (DEC-06), so the director falls back to SAFE or another live camera (RBT-02) and a recovered feed only rejoins after winning full hysteresis+dwell.

Purpose: Close the single most important robustness control (RBT-01/02) using a pure, deterministic, clock-free component the orchestrator drives — the wall-clock lives only in the orchestrator caller (05-06), never in the watchdog.
Output: `segugio.watchdog_feed.liveness.FeedWatchdog` + the fallback/rejoin integration test against the locked `DecisionEngine`.
</objective>
