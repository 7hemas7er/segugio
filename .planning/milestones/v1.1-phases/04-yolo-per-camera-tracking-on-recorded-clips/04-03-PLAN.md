## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| clip file path → cv2.VideoCapture | A configured/resolved clip path crosses into the decoder; a symlink to an absent Windows path (gara_full.mp4) or a malformed/zero-byte file must be handled (skip/loop), never crash or follow a traversal |
| yolo26s.pt weights download → ultralytics cache | The model auto-downloads weights on first use; the UNWANTED yolo26n-cls.pt fallback download is the supply-chain side effect TRK-02 must detect |
| decoded frame → PerCameraTracker.track | An empty/blank/zero-byte frame crosses into YOLO inference; must degrade to "no detection" (coast), never raise |
