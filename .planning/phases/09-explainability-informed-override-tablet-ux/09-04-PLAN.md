<objective>
Land MVW-05 (the switch-history strip) and the UXT-03 long-run tablet hygiene that keeps an iPad on
contended WiFi honest. (1) Switch-history: render the `cuts` ring (now exposed by 09-01) into the
sidebar `#switch-history`, newest-first, with Italian reasons. (2) Flicker-free + leak-free refresh:
replace the per-frame `new Image()` with ONE persistent off-DOM preloader per tile +
`decode()`-before-swap; hidden tiles → 1×1 data-URI. (3) Freshness: a `gen`-age foreground watchdog
(PRIMARY) marks a tile STALE/RICONNESSIONE before any lifecycle event fires, with the "agg. {n}s fa"
/ "frame non aggiornato" stamp — a frozen frame is never labeled "live". (4) Sleep/wake resume:
`visibilitychange` + `pageshow`/`pagehide` wiring tears down + restarts the poll, defers the first
resume fetch ~150-250ms (iOS "Load failed" bug), and renders LIVE only once a frame post-dating
`resumeAt` arrives. Then a BLOCKING on-device acceptance checkpoint (the soak/sleep-wake/freshness
proof that only the physical iPad can confirm).

Purpose: this is the robustness contract — "la preview degrada per prima, il director mai." It must
hold over a multi-hour soak on the real operator tablet, which CI cannot assert.
Output: the switch-history strip, a leak-free decode-swap refresh, a freshness-stamped staleness
watchdog, sleep/wake resume, and a signed-off on-device acceptance.
</objective>
