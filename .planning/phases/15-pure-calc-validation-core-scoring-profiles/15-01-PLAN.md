<objective>
Build `src/segugio/ui/score_calc.py` — the single, pure-stdlib authoritative scoring brain. It exposes `validate(discipline, fields, profile) -> list[{field, message}]` and `compute(discipline, fields, profile) -> dict` for disc Toss&Fetch, disc Freestyle, and agility (both models), driven entirely by an injected `ScoringProfile` plain dataclass. All arithmetic is `decimal.Decimal` (D-09). The module imports ONLY stdlib + `opcomm.records.Discipline` — it never imports `segugio.config`, numpy, cv2, or torch (RBT-08 / Pitfall 1).

Purpose: This is the keystone of milestone v1.3 — the compute authority every later phase (Phase 16 `POST /score`, Phase 17 modal, Phase 18 data model) consumes. It is built and unit-tested STANDALONE here, before any UI touches it (SCC-02, SCC-04).
Output: `score_calc.py` (ScoringProfile + validate + compute) and `tests/test_score_calc.py` (per-discipline unit tests vs the pinned CSEN tables + decimal-exactness + validation-error contract).
</objective>
